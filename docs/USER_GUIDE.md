# 使用说明

## 启动与设置

解压稳定版后双击 FolderNest.exe，无需安装。本机入口为 `D:\FolderNest\产品\FolderNest\FolderNest.exe`。

“添加监控目录”选择真实文件夹，填保留天数、删除方式及启用状态后保存。已有文件从加入开始计时，旧修改日期不导致立即到期。“设置”修改每日时间（默认本地 02:00）、日志总额及新目录默认删除方式，不需要手动部署计划。

## 管理目录

Ctrl 多选，Shift 范围选择，列表右上角全选/全不选。“启用/停用选中”“扫描选中”仅作用于选中项。双击路径编辑，固定字段用下拉，天数用整数微调。无效输入红框且不保存，Esc 撤销。左侧排序柄拖动或上移/下移会保存顺序，不影响计时。

停用保留历史，日历不冻结。删除监控弹出勾选窗口，只删配置及计时，不碰实际文件，重新添加从头计时。“重置计时”单独窗口可选整目录或根文件/一级子文件夹，从确认时重新计时，不改内容、日期、启用状态。一级子文件夹整体处理，不是任意深层文件独立计时。

## 提醒与清理

关机不能物理扫描，已记录截止时间继续推进，登录补扫。无到期项不提醒，每天最多一次。关闭窗口收起托盘，“退出程序”停止进程，但下次登录/每日计划可再次启动。

点击通知或“查看到期清单”，取消勾选要保留的项，选择本次模式并确认。筛选不会取消隐藏项勾选，最终确认显示总数和永久删除数。变化/失联/停用项目跳过并记录。永久删除无法从回收站恢复。

## 配置、备份与升级

“导入监控配置”选择 JSON，校验和预览后新增；详见 CONFIGURATION.md。它不是恢复计时或实时配置文件绑定。

界面底部显示实际数据和配置位置，通常是 EXE 旁 data/ 和 data/foldernest.db。日志默认总额 10 MiB，可调 2–1024 MiB。退出后备份整个实际数据目录，勿直接修改运行中的 DB。

更新替换成品文件但保留 data，旧 SQLite 自动复用。移动整个产品文件夹使数据路径改变时，先备份数据及核实旧 FolderNest Daily/Logon 计划，再删除旧计划并从新位置启动重建。不要从多个数据副本管理同一目录。

此版本没有代码签名，Windows 可能显示 SmartScreen。只使用自己构建或本仓库 Release 产品，核对 SHA256；不要为未知来源软件关闭系统安全保护。
