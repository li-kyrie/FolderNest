# FolderNest 重构实施计划

版本基线：`v1.0.0` 和 `v1.1.0` 历史标签保留。新框架标记 `1.2.0-preview.1`，本轮不新增正式版标签，正式 `v1.2.0` 在完整验收后发布。

## 阶段 0：统一需求与可编译框架（本轮）

- [x] 汇总整段对话的需求及修正，明确离线扫描和首次发现边界。
- [x] 建立 Core / Infrastructure / Desktop 分层以及行为测试项目。
- [x] 接入 SQLite、清单枚举、到期算法、轮换日志，配置从验证到持久化可运行。
- [x] 接入 WPF 目录管理、直接编辑、批量操作和到期预览。
- [x] 独立任务栏图标与 WinExe，自包含发布脚本。
- [x] 构建零警告/零错误、10 项行为测试通过、WPF 主窗口启动冒烟通过，生成独立 D 盘框架预览包。

本轮交付的是能运行、能保存目录、能手动扫描的框架预览。旧 `FolderNest.cmd` 仍打开原型；新预览使用单独 EXE。不会用预览覆盖旧版数据或重部署旧任务。

## 阶段 1：完善配置与实时计时

1. 补回 560×240 的添加/编辑窗，单行启用选项；提供完整 GUI 设置页（扫描时间、时区、日志额度、默认删除模式）。
2. 完成 FileSystemWatcher 进入/变化监听、防抖、首次启用基线、事件溢出校正。
3. 旧 JSON 导入/备份；无效路径提示、目录替换检测、文件身份/重命名处理。
4. 保留 CurrentItem、全部选中项及滚动位置；校验错误拒绝功能操作，避免显示未保存的值却扫描旧配置。

验收：下载旧时间文件不立即到期；目录活动刷新；停用/局部扫描/权限失败不丢历史；空目录正常；外部链接不进入清理范围。

## 阶段 2：定时任务、在线提醒

1. 按目录勾选部署、卸载和重新部署新全局任务；部署失败时回滚或显示部分成功。
2. 配置时间每日扫描、登录/恢复补偿、进程互斥；当次非空到期结果才触发在线提醒。
3. 接入 Toast 和托盘入口，通知点击打开清单，忽略后不追催。
4. GUI 分别显示全局实际任务状态、每个目录参与情况、停用状态；日志含任务名称和目录。

验收：空列表不虚报成功；勾选 A/B 不扫描 C；取消 A/删除 A 后不再自动处理 A；连续开机每日判断；时间后开机补算/提醒；时间前登录不早提醒；无清单当天静默；移动程序重部署正确。

## 阶段 3：确认清单与清理执行

1. 到期清单支持单项勾选、取消勾选、全选/全不选、筛选和分目录默认模式。
2. 实现目标再校验：路径归属、身份/链接替换、修改状态、到期条件；跳过陈旧清单项。
3. 接入 Shell 回收站和永久删除；后者再次确认；显示逐项结果并写有额度限制的日志。
4. 全部清理调用来自 GUI 明确确认，没有自动定时删除入口。

验收：取消项不删除；快捷方式只处理本身；内部更新后跳过；回收站可恢复；锁定/权限失败只影响该项；永久删除确认与日志准确。

## 阶段 4：集成验收与便携发布

1. 实测小屏/高 DPI/默认窗/缩放后按钮换行和无截断；多选与框选不干扰下拉、路径、微调控件。
2. 测试一天到期边界、关机跨多天、暂停恢复、睡眠恢复、空目录、链接、删除失败、程序移动、日志额度、数据回退。
3. 新旧任务切换向导，避免重复提醒；可选择保留/移除旧配置备份。
4. 发布 `v1.2.0`，更新 README 与 GitHub 便携下载；默认无安装包，安装包后续可选。

## 构建方式

需要 .NET 10 SDK。当前工作目录已下载官方便携 SDK 到 `.tools/dotnet/`（忽略进 Git），没有替换系统 dotnet。

```powershell
Set-Location D:\FolderNest
./scripts/build.ps1 -Publish
```

生成：`artifacts/portable/FolderNest.exe` 和 `D:\FolderNest-Framework-Preview-win-x64.zip`。它们是新框架预览，不是最终清理软件。构建脚本先编译所有项目并运行行为测试，失败即停止发布。
