# 框架验证记录

日期：2026-10-10。验证对象：`1.2.0-preview.1` C#/WPF 新框架，不是旧 PowerShell 原型。

验证结果：

- .NET 10 SDK 10.0.401 编译全部四个项目：零警告、零错误。
- 10 项行为回归通过：旧时间戳首次发现、离线到期、活动刷新、选中/停用目录历史保留、空目录/不可访问目录、路径更改及删除监控的隔离、`.lnk`、真实 Windows 联接目标隔离、10 MiB 日志限额、提醒时间与无到期静默、目录验证。
- Windows x64 自包含单文件发布成功，`WinExe` 无控制台入口。
- 发布后的 `FolderNest.exe --smoke-test` 创建 WPF 主窗口并正常关闭，退出码 0。此项会实例化真实窗口和本地存储，但不是鼠标/键盘交互验收。
- ZIP 使用明确打包白名单：EXE、README、LICENSE、docs；不包含运行产生的数据库/日志、旧数据或下载的 SDK。

构建最初发现 SQLite 原生传递依赖的 NuGet 安全告警，已更新到 Microsoft.Data.Sqlite 10.0.12 和 SQLitePCLRaw.bundle_e_sqlite3 3.0.5，最终构建告警为零。联接测试最初的命令转义错误已修复，再运行全部测试通过。

本轮不宣称已完成真实鼠标/键盘 GUI 验收，也不宣称已验证尚未接入的自动部署、离线补偿、通知或删除。测试只在随机临时目录中创建文件，不以用户监控目录作为删除样本。
