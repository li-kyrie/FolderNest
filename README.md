# FolderNest 2.0.0

Windows 本地文件保留期限管理工具。从首次发现文件开始计时，到期后在线提醒；在清单里取消勾选不想处理的项目，再确认移入回收站或永久删除。

2.0 已全面切换到 **C# / .NET 10 + WPF + SQLite**。日常运行只需一个自包含的 `FolderNest.exe`，不再使用 PowerShell、CMD、VBS 或旧版界面。无需安装包或另装 .NET。

## 快速开始

1. 下载便携包并解压到自己选择的位置，例如 `D:\FolderNest`，双击 `FolderNest.exe`。
2. 点击“添加目录”，浏览选择真实文件夹，设置保留天数和删除方式，保存后立即出现在列表。
3. 点击“扫描全部启用”，建立首次计时记录。此前已有文件从首次扫描开始计时，不根据文件携带的旧修改时间提前删除。
4. 打开“设置”，设置每天的检查/提醒时间（默认 **02:00，24 小时制本地时间**）及日志限额。
5. 点击“部署/选择定时任务”，勾选需要自动检查的启用目录，点击“部署并保存”。底部和每行显示实际部署状态。
6. 有到期文件的日子，指定时间后发送 Windows 系统托盘气泡通知。点击通知或“查看到期清单”，选择项目并确认清理。

没有目录或未勾选目录，不会显示部署成功。只在列表将“自动扫描”改为“参与”，不等于任务已部署。

本机成品：`D:\FolderNest\FolderNest.exe`。便携 ZIP：`D:\FolderNest-Portable-v2.0.0-win-x64.zip`。

## 界面操作

| 操作 | 作用 |
| --- | --- |
| 路径单元格双击 | 直接编辑；必须为存在的绝对真实目录。无效输入显示红框且不保存，Esc 撤销无效路径草稿 |
| 保留天数 | 1–36500 的整数；上下按钮和键盘上下键每次增减 1 |
| 状态 / 删除模式 / 自动扫描 | 使用固定下拉选项，修改后立即保存 |
| Ctrl、Shift、从列表空白处拖动 | 多选、范围选择、框选 |
| 启用/停用选中 | 混合状态统一启用，全部启用则统一停用；保留历史，日历时间不冻结 |
| 删除监控选中 | 只移除配置及计时记录，不删除实际文件；其他目录不受影响 |
| 扫描选中 / 扫描全部启用 | 手动检查；未参与自动扫描的目录仍可手动操作 |
| 部署/选择定时任务 | 创建或更新每日和登录两条全局任务，并保存参与目录 |
| 卸载自动任务 | 删除两条全局任务并停止自动跟踪、检查和提醒；不删除监控配置 |
| 查看到期清单 | 先重新扫描，再按当前状态生成清单；不保留冻结的待处理队列 |
| 查看日志 | 使用记事本打开当前日志，轮换日志在同目录 |

顶部功能区随窗口宽度自动换行并调整高度。添加目录窗口为 560×240，启用选项单行显示。操作保留未删除行的选择和当前行。

清单默认勾选所有项目，支持路径筛选、勾选筛选项、取消全部勾选。筛选本身**不会取消隐藏项目的勾选**。“确认清理”会显示所选总数和永久删除数量，再次确认后才执行；也可覆盖本次删除模式。取消勾选只影响本次，不是永久豁免。

## 计时与安全边界

- 根目录的每个文件独立计时；每个一级子文件夹作为整体清理单元，清理该项会处理整个子文件夹。
- 自动任务已完整部署时，只跟踪“启用且参与”的目录。使用文件系统事件记录可观察活动，并每 15 分钟校正一次；每日指定时间再次检查。未参与目录只手动扫描。
- 首次发现、内容元数据变化或观察到目录内部活动时刷新计时。不用下载文件的旧修改日期代替进入时间。
- **关机无法物理扫描**。已保存的到期时间仍推进，登录后补算；程序未运行期间新进入的文件，从首次发现保守开始计时。
- 自动通知每天至多一次；指定时间前登录不会提前提醒。没有到期项不通知，不弹自动清单，也不追催。后续每天按当时状态重新判断。
- 到期清单每次重新计算。执行前重新校验配置、当前观察记录、到期状态、路径和元数据指纹；变化、丢失、停用或访问失败的项目跳过并记录原因。
- 不解析 `.lnk` 目标，只把快捷方式自身当文件。扫描跳过符号链接/联接等重解析点，清理拒绝包含这些链接的目录，避免递归进入链接目标。
- 指纹使用路径、大小、修改时间、创建时间等元数据，不是文件内容哈希或 NTFS USN 历史。离线期间恢复完全相同元数据的特殊改动可能无法识别；不应当作备份或对抗恶意并发替换的安全沙箱。重要数据请保留备份。
- 回收站受 Windows、磁盘类型、容量和网络路径等限制；可恢复性由系统决定。重要目录建议先用测试文件试用，不要对唯一副本配置永久删除。

## 提醒、托盘与定时任务

任务名称为 `FolderNest 2 <当前用户 SID> Daily` 和 `… Logon`。任务以当前用户交互会话启动 EXE 的 `--background --data "绝对数据路径"` 模式，不保存密码、不申请管理员权限、不自动删除文件。

程序驻留托盘提供观察和提醒；关闭主窗口时，若仍有自动任务会收起到托盘。没有自动任务时关闭窗口即退出。“退出程序”明确停止本次进程；Windows 任务仍保留，下次登录或每日触发时重新启动。同一数据目录只运行一个实例，再次启动唤回窗口。

系统通知的展示时间和可见性受勿扰模式等 Windows 设置控制；程序不强制通知常驻。未看到通知可从托盘或主窗口重新查看清单。

同一用户仅维护一组正式自动任务。把程序移动到其他位置前先卸载自动任务，关闭程序，移动 EXE **和数据文件夹**，再在新位置重新部署。仅复制 EXE 会得到新配置，原任务路径不会自动跟着移动。

## 程序和数据放在哪里

程序本体可以放 D/E 盘等可写位置，不要求 C 盘。

| 位置 | 内容 |
| --- | --- |
| `FolderNest.exe` | 正式 GUI、后台跟踪与任务入口，内置 .NET 运行时和图标 |
| EXE 旁 `data/foldernest.db` | SQLite：监控配置、首次发现/活动时间、设置、最近提醒日期 |
| `data/logs/foldernest.log`、`.log.1` | 当前日志与一个轮换文件，总额默认 10 MiB，设置中可改为 2–1024 MiB |
| `data/foldernest.lock` | 运行时独占锁，不是用户文件 |
| 已有 `data-v2/foldernest.db` | 升级同位置的框架预览时优先复用，不覆盖已有预览记录 |
| `%LOCALAPPDATA%/FolderNest/v2` | 程序旁不可写时的备用数据位置；主界面会明确显示 |
| Windows 单文件运行时缓存 | 由 .NET 自解压原生库，可能使用系统用户临时目录；不属于配置库 |

主界面底部显示**实际使用的数据位置**。备份时先退出程序，再复制整个数据文件夹（不要只复制正在使用中的单个 DB）。日志可能含本机文件名和路径，不会被自动上传。

## 从旧版升级

`v1.0.0` / `v1.1.0` 标签与 Git 历史保留。2.0 源码移除了旧 `.ps1/.cmd/.vbs` 启动和任务安装脚本，不需要同时运行两个框架。

旧的 `data/config.json`、`state.json` 和日志不删除、不提交 Git。点击“导入旧版配置”选择 `config.json`，导入路径、天数、方式和启用状态；不会导入旧 Pending/FirstSeen，首次扫描重新计时。重复/重叠目录会拒绝并提示。导入后需重新选择并部署新版任务。

本机旧版 `FolderNest Daily` 任务在此次升级中已备份 XML 并退役，以免调用已移除脚本；备份位于 `data/legacy-backup/`。旧脚本可从历史标签恢复。

## 源码和构建

- `src/FolderNest.Core`：类型化规则、到期策略、扫描与清理确认执行。
- `src/FolderNest.Infrastructure`：SQLite、文件指纹/监听、回收站、任务计划、便携路径及轮换日志。
- `src/FolderNest.Desktop`：WPF 主窗口、目录/设置/任务/清单对话框、托盘与单实例入口。
- `tests/FolderNest.Tests`：规则与真实 Windows 适配器测试；只删除自动创建的测试文件，使用临时任务名称。
- `tests/FolderNest.Desktop.Tests`：界面绑定、校验、对象稳定性和窗口组件测试。
- `scripts/build.ps1`：开发者构建、测试和打包脚本，不是用户运行依赖。

开发需要 Windows x64 和 .NET 10 SDK，优先使用工作区 `.tools/dotnet` 下的 SDK，否则使用 PATH 中的 dotnet：

```powershell
./scripts/build.ps1
./scripts/build.ps1 -Publish
```

发布脚本运行测试、生成自包含 EXE、执行独立数据目录的启动冒烟测试，再按白名单打包。ZIP 不含个人配置、数据库、日志、SDK 或测试夹具。
