# FolderNest

FolderNest 是一个 Windows 本地文件保留期限管理工具：从首次观察到文件进入目录开始计时，达到设定天数后在用户在线时提醒，由用户勾选确认后移入回收站或永久删除。

## 重构框架：1.2.0-preview.1

2026-10-10 根据完整对话统一需求，建立 **C# / .NET 10 LTS + WPF + SQLite** 框架。所有工作位于 `D:\FolderNest`。历史 PowerShell 原型保留，新框架使用单独的原生 GUI EXE。

- [统一需求规格](docs/REQUIREMENTS.md)：全部需求、修正及明确的实现约定。
- [架构与数据设计](docs/ARCHITECTURE.md)：模块职责、存储、计时、调度和便携路径。
- [分阶段实施计划](docs/PLAN.md)：本轮框架、后续监听、任务提醒、清单删除、发布验收。
- [验证记录](docs/VALIDATION.md)：本轮实际验证范围与未覆盖项。

本轮可运行：添加目录、验证后直接编辑、天数微调、Ctrl/Shift 多选、空白区域框选、批量启停/移除监控、全量/选中手动扫描、SQLite 保存、到期清单预览、旧 Windows 任务状态查询与轮换日志。

**本轮尚未接入：在线进入事件监听、自动任务部署、Toast/托盘、勾选清单的实际文件删除、旧配置导入和完整设置页。** 当前预览不会自动替换旧版，也不会操作监控文件的删除。

框架预览：`D:\FolderNest\artifacts\portable\FolderNest.exe`。
便携包：`D:\FolderNest-Framework-Preview-win-x64.zip`，解压后直接双击 `FolderNest.exe`。程序为自包含 Windows x64 GUI，不需要 PowerShell 或另装 .NET 运行时；框架数据位于 EXE 旁 `data-v2/`。原 `data/` 和旧 `FolderNest.cmd` 保留。

```powershell
Set-Location D:\FolderNest
./scripts/build.ps1 -Publish
```

构建需要 .NET 10 SDK，本工作目录的官方便携 SDK 位于 `.tools/dotnet/`，不提交 Git。构建脚本先编译并运行行为回归，再生成便携 EXE/ZIP。

关机期间不能实际扫描。已记录文件的到期日仍按时间推进，开机补算；未运行期间进入的文件从首次发现保守计时。到期清单实时从元数据派生，不额外保存永久待处理队列。

## 历史原型：v1.1.0

以下是旧 PowerShell 版的使用说明。历史实现的行为和不足已在需求文档中核对，不应将下面的功能说明当作新框架已完成全部功能的证明。`v1.0.0` / `v1.1.0` 标签保持原提交。

这是无需安装 .NET 的 PowerShell 5.1 便携版，全部日常操作都通过图形界面完成：

- 同时添加多个监控目录；
- 每个目录独立设置保留天数、删除模式和启用状态；
- 列表支持直接编辑状态、路径、天数和删除模式，并对路径、整数天数进行校验；
- 支持 Ctrl/Shift 多选和鼠标拖动范围选择，可批量扫描、启停或删除监控；
- 单独编辑、停用或删除某个监控目录（删除监控设置不会删除目录内容）；
- 每天 02:00 扫描，关机错过后在用户登录时补扫；
- 安装定时任务时可勾选需要参与自动扫描的监控目录；
- 无到期项目时不弹出提醒；
- 主界面显示定时任务是否已部署，并使用独立 FolderNest 图标显示在任务栏；
- 到期清单支持全选、全不选、移入回收站和永久删除；
- 文件夹内部递归统计，内部任何文件更新都会刷新整个文件夹的有效时间；
- 日志上限 10 MB，自动截断旧内容；
- 整个程序目录可放在 D 盘、E 盘或其他本地磁盘。

## 快速开始

1. 将 `FolderNest` 文件夹复制到任意位置，例如 `D:\FolderNest`。
2. 双击 `FolderNest.cmd` 打开主界面。
3. 点击“添加目录”，选择要监控的文件夹，设置保留天数和删除模式。
4. 点击“安装定时任务”，注册每日 02:00 扫描和登录补扫。
5. 日常需要时点击“立即扫描”或“到期清单”；没有待处理项目时不会弹窗。

双击 `FolderNest.cmd` 时只显示图形界面，程序窗口会出现在 Windows 任务栏中，不保留命令行窗口。

也可以双击 `Install-FolderNest.cmd` 直接安装任务计划；如果尚未配置目录，仍建议随后打开主界面添加目录。

## 主界面操作

| 按钮 | 作用 |
|---|---|
| 添加目录 | 新增一个独立监控目录 |
| 编辑 | 修改选中目录的路径、天数、删除模式和启用状态 |
| 启用/停用 | 暂停或恢复选中目录的扫描 |
| 删除监控 | 只删除监控设置，不删除目录和文件 |
| 立即扫描 | 立即扫描全部已启用目录 |
| 到期清单 | 打开可勾选的待处理清单 |
| 查看日志 | 用记事本查看日志 |
| 安装/卸载定时任务 | 管理 Windows 任务计划程序 |

点击“安装定时任务”后，会先列出当前已启用的监控目录。勾选的目录参与每日 02:00 扫描和登录补扫；取消勾选的目录仍保留在列表中，但不会被定时任务处理。没有可用目录或未勾选任何目录时，不会报告安装成功，并会写入日志。

## 计时规则

- 根目录下的单个文件独立计时。
- 每个一级子文件夹作为整体计时和删除，不拆分其中的文件或下级目录。
- 有效时间取“首次发现时间”和“内部最新文件修改时间”中较晚者。
- 新下载但带有旧修改时间的文件，首次发现时不会立即被误判为过期。

## 数据位置

便携版默认使用程序旁的 `data` 文件夹：

```text
FolderNest\data\
├── config.json       多监控目录配置
├── state.json        首次发现时间和待处理清单
└── foldernest.log    扫描、提醒和删除日志（上限 10 MB）
```

如果程序目录不可写，会自动回退到 `%LOCALAPPDATA%\FolderNest\`。程序不会复制或上传监控目录中的文件，只保存路径、时间、大小和状态等元数据。

## 安全说明

- 通知消失、点击“取消”或关闭窗口，都不会自动删除文件。
- 默认删除模式为移入回收站；永久删除需要在清单窗口再次确认。
- 删除监控设置不会影响原目录内容。
- 如果程序目录被移动，需重新点击“安装定时任务”以更新任务路径。
